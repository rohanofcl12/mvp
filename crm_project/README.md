## Screenshots

### Dashboard
Shows KPI cards (Total Leads, Visits Today, Closed Deals, Lost Deals) and two charts:
- Leads by Stage (doughnut chart)
- Daily Lead Inflow (line chart)

### Leads Page
Table view with columns: Name, Phone, Source, Agent, Stage, Score, Actions.
- Score appears as a bold number (computed from source)
- Actions: Edit, Delete, and stage quick-update dropdown
- Click name to open timeline modal

### Pipeline Board
Kanban-style board with columns: New, Contacted, Visit Scheduled, Visit Done, Closed, Lost.
- Drag-and-drop cards between columns to update stage
- Each card shows: name, phone, score, assigned agent

### Visits Page
Table of scheduled visits with columns: Lead, Agent, Date, Time, Location, Status (dropdown), Notes.
- Status can be changed directly from table (Scheduled/Completed/Cancelled)
- "Schedule Visit" form at top

### Agents Page
Grid of agent cards showing avatar (initials), name, role, email, phone.
- "Add Agent" button opens inline form
